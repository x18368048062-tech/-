# 简易保险计划书工作台

一个本机运行的保险产品计划书网页，包含鑫享世家和泰盈人生产品方案，可按投保信息生成利益演示，并支持打印或导出。

## 本机使用

直接在浏览器打开 `index.html`。泰盈人生方案可从首页产品入口切换；`taiying.html` 是该方案页面。页面依赖同目录中的 `workspace.js`、`source-data.js` 和 `projection-data.js`。

方案历史保存在浏览器本地。客户历史备份和账号数据不包含在本代码库中。

## 文件

- `index.html`：鑫享世家计划书工作台
- `taiying.html`：泰盈人生计划书页面
- `workspace.js`：本地方案历史功能
- `source-data.js`、`projection-data.js`：计划书演示数据

计划书内容仅供沟通参考，具体保险责任、现金价值及相关权益以保险合同条款为准。
