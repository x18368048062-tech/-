# 简易保险计划书工作台

一个本机运行的保险产品计划书网页，包含鑫享世家和泰盈人生产品方案，可按投保信息生成利益演示，并支持打印或导出。

## 本机使用

直接在浏览器打开 `index.html`。鑫享世家尊享版和庆典30在同一页面顶部切换，各自使用自己的源表和缴费期。泰盈人生原有入口继续保留；`taiying.html` 是该方案页面。页面依赖同目录中的 `product-data.js`、`workspace.js`、`source-data.js` 和 `projection-data.js`。

方案历史保存在浏览器本地。客户历史备份和账号数据不包含在本代码库中。

## 文件

- `index.html`：鑫享世家计划书工作台
- `taiying.html`：泰盈人生计划书页面
- `workspace.js`：本地方案历史功能
- `product-data.js`：从两份产品源表读取的完整精度系数，不提前舍入红利
- `source-data.js`、`projection-data.js`：计划书演示数据

## 源表核对

尊享版支持1、3、5、10年缴费；庆典30支持1、3、6、10、15、20年缴费，实际可选项随年龄和性别过滤。两款产品共同复用页面、领取计划和PDF/PNG/Excel导出。

2026-09-29重新读取用户提供的两份源表。身故给付按源表G/P/Z列处理缴费结束后的有效保额比较；交通意外给付按AA列合计基本保额及交清增额部分。保留源表精度，仅在显示时取整。

`node validation/check-source.cjs`核对源表已保存的两个示例（1,950项数值），并检查1,318种投保组合、95,443个保单年度及领取上限。该检查不等同于在Excel中重新计算所有组合。

计划书内容仅供沟通参考，具体保险责任、现金价值及相关权益以保险合同条款为准。
